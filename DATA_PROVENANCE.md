# TokenCapBench Data Provenance

## Asset Types

TokenCapBench combines upstream benchmark task sources with new benchmark artifacts produced by the TokenCapBench protocol.

| Asset type | Examples | Origin |
|---|---|---|
| Upstream task content | GSM8K, MATH/MATH-500, EvalPlus HumanEval+/MBPP+, BigCodeBench-Hard, CanItEdit, LiveCodeBench | external benchmark projects |
| TokenCapBench task records | JSONL files in `data/processed/` | normalized records derived from upstream tasks |
| TokenCapBench forecasts | `forecasts.jsonl` and top-level forecast snapshots | generated by evaluated models before capped solver runs |
| TokenCapBench outcomes | `outcomes.jsonl` and top-level outcome snapshots | generated by capped solver runs plus verifier labels |
| TokenCapBench summaries | metrics, tables, figures, manifests, Croissant metadata | generated by repository scripts from frozen artifacts |

## Source Summary

| Source | Release role | Notes |
|---|---|---|
| GSM8K | core math | Grade-school math word problems loaded through the repository task adapter. |
| MATH / MATH-500 | core math | Competition-style math tasks with symbolic and numeric answer handling. |
| EvalPlus HumanEval+ | core coding | Standalone Python function tasks verified with EvalPlus. |
| EvalPlus MBPP+ | core coding | Standalone Python programming tasks verified with EvalPlus. |
| BigCodeBench-Hard | extension | Harder standalone coding tasks labeled through the official BigCodeBench package path. |
| CanItEdit | extension | Code-editing tasks evaluated with provided tests. |
| LiveCodeBench | appendix | Fresh coding subset used as a scoped freshness check. |
| SWE-bench, BFCL, tau-bench, AssistantBench, Aider Polyglot | optional bridge/config support | Not used as core evidence in the current release. |

## Licensing and Terms

The repository code is MIT licensed. Upstream task content remains governed by the upstream benchmark licenses and terms. Before redistributing raw task text outside this repository or a conference artifact bundle, verify the current upstream license and citation requirements for each source.

TokenCapBench-generated forecasts, verifier outcomes, metrics, tables, figures, manifests, and metadata are released as benchmark artifacts under the repository license unless an upstream source license imposes additional constraints on the derived task content.

## Reproducibility Fields

Task and artifact records include fields such as source name, suite name, budget grid, model identifier, verifier metadata, run manifest hashes, and SHA-256 manifests. Where an upstream dataset exposes stable revisions or versions, future hosted releases should pin those identifiers explicitly in the normalized task metadata.

## Data Quality Notes

- Core math labels depend on answer extraction plus numeric or symbolic matching.
- Coding labels depend on unit-test or official-harness coverage.
- CanItEdit uses provided tests rather than hidden tests.
- Public benchmark contamination is possible for established datasets.
- Provider raw responses are not required for public scoring and are removed from release-facing outcome artifacts.
